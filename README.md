# 📉 Tech Layoffs Dashboard 2020–2023 (Power BI)

An interactive Power BI dashboard analyzing global tech layoffs by company, year, and company funding stage.

![Dashboard](dashboard_page1.png)

## 📌 Overview
- **Period:** 2020–2023
- **Total layoffs analyzed:** ~252K employees
  

## 🛠️ Tools
- Power BI Desktop

## 📊 Visuals
- Total Layoffs by Company (bar chart)
- Total Layoffs by Year (line chart)
- Layoffs over time with date drill-down (column chart)
- Total Layoffs by Company Stage (donut chart)

## 💡 Key Insights
- Layoffs **peaked in 2022 (~104K)**, up sharply from ~16K in 2021.
- **2021 was the lowest year** (~16K), after ~51K in 2020.
- **Post-IPO companies account for ~63%** of all layoffs (~160K).
- **Amazon** had the highest layoffs, followed by Google, Meta, and Microsoft.
